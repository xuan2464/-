绝影 Lite3 · 相机画面 + 运动控制后端（独立副本）
====================================================

这个文件夹是 C:\Users\eeeee\Desktop\机械狗 的完整副本，可以整个拷走单独使用。
Pillow 已经打在 .deps\ 里，不需要联网 pip 安装。

一、在 Windows 上本机看演示画面
  1) 双击「本地演示.bat」（会用合成画面，不需要机械狗）
  2) 浏览器打开 http://127.0.0.1:8080

二、连真正的机械狗
  1) 网线连机器狗，把有线网卡设成静态 192.168.1.50 / 255.255.255.0
  2) 双击「连接机器狗.bat」，按提示输密码（机器狗登录密码是一个英文单引号 '）
  3) 部署完成后浏览器打开 http://192.168.1.103:8080

三、命令行启动（等价于双击）
  python run.py --source auto --port 8080
  python run.py --source ros        # 机器狗上走 ROS 话题（推荐）
  python run.py --source demo       # 纯合成画面，不需要硬件

四、给别的网站/程序用的接口
  文档：docs\API.md（curl / JS / Python 示例、CORS、令牌、错误码、UDP 协议附录）
  能力自检：http://<地址>:8080/api/v1/info
  在线示例：http://<地址>:8080/api-demo
  OpenAPI：http://<地址>:8080/api/v1/openapi.json（可导入 Postman / Apifox）

五、加访问令牌（暴露到公网时强烈建议）
  python run.py --source auto --port 8080 --api-token 你的口令
  之后写接口要带请求头 X-API-Token: 你的口令；急停 /api/v1/motion/stop 永远免令牌。

六、文件说明
  run.py                  入口
  lite3_viewer\           取流 / 编码 / MJPEG 服务 / 运动控制（UDP 43893）
  static\                 网页（画面页 + 控制页 + api-demo.html 第三方接入示例）
  docs\API.md             后端接口文档（给别的网站看的）
  docs\*.png              真机截图
  tools\                  部署脚本（connect.ps1 / robot_setup.sh / robot_start_camera.sh）
  .deps\                  Pillow 便携依赖（可删除，但删了就没有 JPEG 编码器）
  连接机器狗.md           连线、静态 IP、排错手册
